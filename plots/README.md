# Plot scripts

Stand-alone scripts. Each reads a sweep summary or the phenotype table and writes a PNG/PDF next to its input.
- `plot_barplot_test_auc.py`: test AUC by cell type × sex (`summary_all_celltypes_by_sex.csv`, `;`-separated, decimal `,`).
- `plot_dotplot_poa_by_{hdl26,crp26ns}_tertile*.py`: PaceOfAgingP45 by age-26 HDL / CRP tertile.
